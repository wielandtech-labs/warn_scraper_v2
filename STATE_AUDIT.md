# State Data-Quality Audit

Living triage of per-jurisdiction WARN data quality. The table is **generated**,
not hand-maintained — regenerate it from a trusted environment:

```bash
# In-cluster, once the image containing the `audit` command is deployed
# (uses prod DATABASE_URL via secretKeyRef — no credentials leave the cluster):
warn-v2 audit --markdown
```

Paste the output between the GENERATED TABLE markers below, then hand-annotate the
**Source notes** section with Part-B findings (archive URLs, source caveats).

The audit logic lives in `warn_v2/scripts/audit.py` (`warn-v2 audit`). Everything in
the generated table is derived from the DB in a single pass; the **Source notes**
and **Backlog** sections are curated by hand from live-source inspection.

## Rubric

Each jurisdiction is scored on:

1. **Field completeness** — % non-null per model field the source could supply:
   `effective_date`, `layoff_count`, `closure_type`, `address`, `raw_notice_url`,
   `pdf_path`, `location_id`, company `naics_code`.
2. **PDF coverage** — for direct-PDF states (`raw_notice_url_is_pdf=True`): % of
   notices with a stored `pdf_path`, and whether the source URLs still resolve.
3. **Backfill / year completeness** — per-year notice counts; empty interior years
   are flagged; check whether an archive URL covers the gap.
4. **Geocoding accuracy** — NULL coords, coords outside the state bbox, and notices
   carrying a street address that should be street-level geocoded.

Plus the recurring failure modes (the `flags` column / `audit.py`): superseded
duplicates, estimated-vs-real `effective_date`, dead source links, HQ-vs-worksite
address, silent row-count drift, scraper failures, date/count sanity, low
enrichment.

## Legend

**Status**

| Symbol | Meaning |
|--------|---------|
| complete | No gap flags (a lone `has_superseded` note still counts complete). |
| gaps | One or more data-completeness flags (geo, pdf, dates, years, enrichment). |
| broken | Scraper failing, dead links, or silent row-count drift. |
| blocked / no data | Source unavailable, or no rows in DB. |

**Flags** (emitted by `warn-v2 audit`)

| Flag | Meaning | Remediation |
|------|---------|-------------|
| `low_geo` | <95% of notices geocoded | `backfill-geo` / `backfill-geo --rerun-address --state XX` |
| `out_of_state_coords` | geocoded point outside state bbox | fix geocode / verify worksite vs HQ address |
| `missing_pdf` | <90% PDF coverage on a PDF state | `download-pdfs --state XX` |
| `no_effective_date` | <50% have an effective_date | `backfill-effective-dates --state XX` |
| `mostly_estimated_dates` | >50% of effective_dates are the notice+60d estimate | source detail/PDF for real dates |
| `year_gaps` | empty interior year(s) | `backfill-historical --state XX` (extend `_SUPPORTED` if new) |
| `has_superseded` | superseded duplicates present | `mark-superseded --state XX --dry-run` then commit |
| `low_enrichment` | <50% of notices have an enriched company | `enrich --state XX` |
| `dead_links` | sampled `raw_notice_url`s 404 | fix scraper URL pattern (new code) |
| `row_drift` | last OK run below `expected_row_range` min | `heal --state XX` (silent partial parse) |
| `scraper_*` | last run status not `ok` | `heal --state XX` |
| `date_sanity` | future notice_date or effective<notice | inspect parser date handling |
| `count_outliers` | layoff_count <=0 or >50,000 | inspect parser count handling |
| `blocked` / `no_data` | known-blocked source or empty | re-check source access |

## Source notes (hand-curated)

Findings the DB can't tell us — confirmed against the live sources.

- **AK** — `raw_notice_url` values are stale 2016-pattern links
  (`labor.alaska.gov/RR/notices/<Name>_WARN_notice.pdf`) that 404. Needs the
  current AK URL pattern; until fixed, `download-pdfs` can't refresh AK PDFs.
  Quantify with `warn-v2 audit --state AK --check-links`.
- **CO** — Google Sheets export is cumulative since 2019; excluded from
  `backfill-historical` by design (re-ingest would duplicate).
- **CA / DC / AZ / DE** — current-year-only sources; historical years come from
  `backfill-historical`. CA archive = 11 PDFs + 1 XLSX (FY2014–2025).
- **GA** — `raw_notice_url` is a TCSG GravityView HTML entry page, not a PDF
  (`raw_notice_url_is_pdf=False`); enriched by `enrich-ga`. TCSG rate-limits after
  ~10 fast requests (3s inter-request delay required). `Company Address` is often
  the corporate HQ, not the GA worksite → Census no-match / out-of-state coords.
- **KY / MT** — county-only sources; geocoded via Tier-4 county centroid.
- **Blocked (not registered scrapers; appear in the audit only if legacy rows
  exist):** AR (confidential by law), NH (no public listing), OK
  (Salesforce/Aura auth wall), TN (scraper built; tn.gov blocks container IPs),
  WY (no public data). Re-verify each blocker periodically.

## Backlog (genuinely new code, not just a command)

- **AK** URL-pattern fix (see Source notes).
- Any state the audit flags `dead_links`, `row_drift`, or persistent `scraper_*`.
- States whose source exposes a field we don't yet capture (confirm via Part-B
  spot check before writing extraction code).

## Optional enhancement

`Location` has no `geocode_source`/tier column, so the audit *infers* geo accuracy
(address availability + coord presence) rather than reading a stored tier. For
precise, re-runnable geo-accuracy tracking, add a nullable `geocode_source` column
to `Location` (small Alembic migration) and set it in `geo/geocoder.py` +
`pipeline/storage.py`.
