**Subject:** Open records request — historical WARN Act notices

Dear Records Custodian,

Pursuant to Iowa Code chapter 22, I request copies of all electronically available
records of Worker Adjustment and Retraining Notification (WARN) Act notices
received by Iowa Workforce Development, from the earliest electronically available
date through December 31, 2020. Notices from 2021 onward are already published in
the WARN log on workforce.iowa.gov; this request covers the years before that. A
complete export through the present is equally welcome if that is easier to
produce.

I am making this request on my own behalf for an independent, public-interest data
project that tracks WARN layoff notices; the records are not sought for any
commercial purpose.

My preferred format is a spreadsheet export (CSV or XLSX) in the same shape as the
published WARN log, including, where available: employer name, worksite
address/city/ZIP, notice date, layoff or closure effective date, number of
affected workers, and the closure/layoff type. Copies of the underlying notice
letters (PDF) are an acceptable alternative if no tabular export exists.

Please deliver the records electronically to this email address. If fees would
exceed $25, please send me an estimate before fulfilling the request — I am happy
to narrow the scope. If any portion of this request is denied, please cite the
specific exemption relied upon.

Thank you for your time.

Sincerely,
